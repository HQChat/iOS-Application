Trademark and naming policy
The source in this repository is under a permissive licence (see LICENSE).
That licence covers code. It does not grant any right to the project's
name, icon or domain, and this file says so explicitly rather than leaving it
to be inferred.
The marks
	•	the name hqChat / hqchat, in any capitalisation
	•	the hqChat app icon and any derivative of it
	•	the domain hqchat.app and the App Store listing name
What you may do without asking
	•	Refer to the project. "a fork of hqChat", "compatible with the hqChat
protocol", "based on hqChat", "originally by the hqChat project" — nominative
use that describes a factual relationship is fine and always will be.
	•	Write about it. Research papers, reviews, security analyses, talks,
teaching material. Name it freely; quote it; criticise it.
	•	Build it yourself and run it. Compiling this source for your own use,
including modified, is what the licence is for.
What you may not do without written permission
	•	Ship a modified build under the name hqChat, or under a name close
enough to be confused with it, in any app store or distribution channel.
	•	Use the app icon, or a recognisable derivative, on any build that is not
an official release.
	•	Imply endorsement, affiliation, review or approval by this project — for
a fork, a service, a product, or a security claim.
	•	Register the name, a translation or transliteration of it, or a
confusingly similar mark, as a trademark or as a domain intended to be taken
for this one.
Why this exists, in one paragraph
This is an end-to-end encrypted messenger. Its entire trust argument is that
you can read the code that makes the claim. A permissive licence means anyone
may take that code, change it — including in ways users would not want — and
ship the result. That is deliberate and it is the price of the licence. What it
must not become is a build that does something different while wearing this
name, because a user choosing it cannot tell the two apart. Forks are welcome.
Forks under this name are not.
Unofficial builds
If you distribute an unmodified build compiled from this source, you may
say so — "unofficial build of hqChat", "built from hqChat source" — as long as
the application's own display name is not hqChat and the icon is not ours.
Note that these builds are not reproducible today, so a third party cannot
verify that an "unmodified" build is unmodified. Do not claim more than that.
